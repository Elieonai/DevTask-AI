# 📌 DevTask AI

## 📖 Visão Geral

O DevTask AI é uma plataforma moderna de gerenciamento de tarefas com Inteligência Artificial, desenvolvida para ajudar usuários a organizar projetos, aumentar a produtividade e acompanhar seu desempenho de forma simples e intuitiva.

O projeto será desenvolvido seguindo boas práticas de arquitetura, Git Flow, componentização, Design System e Clean Code.

---

# 🎯 Objetivo

Criar uma aplicação SaaS moderna que permita:

- Gerenciar tarefas
- Organizar projetos
- Criar subtarefas
- Definir prioridades
- Acompanhar produtividade
- Utilizar IA para auxiliar no planejamento de atividades

---

# 👥 Público-alvo

- Estudantes

# 🤖 Inteligência Artificial

O usuário poderá escrever algo como:

"Preciso entregar meu projeto React até sexta."

A IA irá:

- dividir em tarefas
- criar subtarefas
- sugerir prioridades
- organizar cronograma
